## Тема

`ColaBikeTheme(darkTheme, dynamicColor = false)` в `core:designsystem`.

| Роль | Светлая | Тёмная | Откуда |
| --- | --- | --- | --- |
| `primary` / `onPrimary` | чёрный / белый | белый / чёрный | главное действие сайта: чёрное на светлом, белое на тёмном |
| `tertiary` / `onTertiary` | `#F3B51B` / чёрный | `#F3B51B` / чёрный | жёлтый ColaBike: акцент и выбор, не текст на светлом фоне |
| `tertiaryContainer` / `on…` | `#FDF3DB` / `#86640F` | `#302A19` / `#F5C03D` | `--accent-soft` и `--accent-text` сайта |
| `background`, `surface` | белый | `#0B0F19` (gray-950) | холст сайта |
| `onSurfaceVariant` | gray-600 | gray-400 | вторичный текст, контраст ≥ 4.5:1 |
| `outline` / `outlineVariant` | gray-300 / gray-200 | gray-700 / gray-800 | рамки полей и hairline-линии карточек |
| `error` | red-600 | red-400 | |

Остальные роли бренда собраны в `ColaTheme.colors`: `like`, `accentText`, `success`, `warning`.

- Брендовая тема включена по умолчанию. `dynamicColor` — сознательная опция, а не умолчание.
- Шрифт — Source Sans 3 (латиница и кириллица), вариативный TTF лежит в `res/font`. Провайдер шрифтов не используется: на устройствах без Google-сервисов его нет. Лицензии OFL и Apache 2.0 (иконки) — в `res/raw`.
- Шкала шрифта — Material в размерах сайта (тело 14 sp, текст для чтения 16 sp), всё в `sp`.
- Формы: 4, 8, 12 (карточки), 16, 28 dp. Отступы — сетка 4 dp, объект `Spacing`, сырые числа на экранах запрещены.
- Иконки — Material Symbols Rounded как vector drawable (`ColaIcons`). Новую иконку кладите туда же в том же формате.
- Глубина: сначала hairline (`OutlinedCard`), тени — только у плавающих слоёв.

## Движение

- Нужен Material 3 Expressive, но в stable material3 1.4 он закрыт: `MaterialExpressiveTheme`, `MotionScheme.expressive()` и компоненты Expressive помечены internal или доступны только в 1.5-alpha. Пока токены пружин Expressive лежат в `ColaMotion` (`spatial`, `fastSpatial`, `effects`…). Когда выйдет stable 1.5, тема переедет на `MaterialExpressiveTheme`, это записано в ADR.
- Системное «Убрать анимации» отключает анимации Compose. Скелетоны в этом режиме не пульсируют (`LocalReducedMotion`).

## Компоненты

| Компонент | Назначение | Доступность |
| --- | --- | --- |
| `BikeCard` | фото 4:3 сверху, имя (2 строки), «бренд модель · год», автор и счётчики; бейдж «Бывший» | одна фраза для TalkBack и одно действие «Открыть» |
| `RideCard` | название и статус (План / Состоялась), дата, расстояние, время в движении, велосипед | одна фраза, одно действие |
| `UserRow` | аватар, имя, @username; вся строка — цель касания | роль кнопки, подпись действия |
| `Avatar` | фото или первая буква на жёлтом фоне | декоративный: читается имя рядом |
| `BikeCardSkeleton`, `SkeletonGroup` | загрузка списка | группа объявляет «Загрузка» один раз |
| `EmptyState`, `ErrorState`, `LoadingState` | пусто / ошибка с «Повторить» / короткое ожидание | заголовок помечен `heading`, ошибка объявляется `liveRegion` |

Кнопки, поля, чипы, верхние панели и навигация берутся из Material 3 без обёрток. Цвета, формы и шрифт они получают из темы.

## Адаптивность

- Окна по классам Material:
  - compact (< 600 dp) — нижняя навигация, одна панель;
  - medium (600–839 dp) — rail, одна панель;
  - expanded (≥ 840 dp) — rail, список и карточка рядом (`ListDetailSceneStrategy`).
- Не растягиваем телефонный макет. Сетка карточек — `GridCells.Adaptive(280 dp)`. Колонки для чтения ограничены (`widthIn(max = …)`: вход 420 dp, карточка велосипеда 840 dp).
- Edge-to-edge с первого кадра (`enableEdgeToEdge`). Отступы от системных панелей задают `Scaffold`, навигационный suite и `safeDrawingPadding` на входе. Клавиатура не перекрывает поля (`imePadding`).

## Состояния экрана

У каждого экрана со списком или загрузкой есть четыре состояния, и каждое снято на скриншоте:

1. загрузка — скелетон по форме будущего контента, а не спиннер посреди пустоты;
2. содержимое;
3. пусто — что здесь будет и куда идти;
4. ошибка — что случилось (из `UiText`) и «Повторить». При ошибке следующей страницы список остаётся на месте, а повтор появляется в его конце.

## Definition of done для UI

- Скриншоты Roborazzi: светлая и тёмная тема. Экраны снимаются в compact и expanded, компоненты — ещё и с шрифтом 200 %. Эталоны лежат в `src/test/screenshots`, а `verify` сравнивает их попиксельно.
- TalkBack:
  - у кнопок-иконок есть `contentDescription`;
  - декоративные иконки помечены `null`;
  - карточка читается одной фразой;
  - заголовки экранов и секций помечены `heading()`.
- Цели касания не меньше 48 dp (у компонентов Material это включено по умолчанию). Контраст текста не ниже 4.5:1 в обеих темах.
- Поля ввода: тип клавиатуры, IME-действие, autofill (`contentType`), видимость пароля переключается кнопкой с подписью.
