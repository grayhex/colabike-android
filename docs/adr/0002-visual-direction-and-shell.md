# ADR 0002. Визуальное направление и навигационная оболочка

Статус: принято в рамках [issue #3](https://github.com/grayhex/colabike-android/issues/3), 03.10.2026. Дополняет [ADR 0001](0001-platform-baseline.md), не отменяя его. **Частично заменено [ADR 0023](0023-graphite-lime-redesign.md)** (06.10.2026): разделы «Визуальное направление» и решение о плавающей панели навигации больше не действуют; остальное в силе.

## Визуальное направление

Источник визуала — Twilight Stillness (Sleek), вместо незаконченного Figma и прежних правил. Источник, соответствие токенам и все адаптации записаны в [docs/design/twilight-stillness.md](../design/twilight-stillness.md); оригинальный DESIGN.md лежит рядом без изменений.

Решения, которые стоит помнить:
- **Тёмная тема — референс, светлая — наша адаптация.** Референс односторонний, поэтому светлую тему мы вывели из тех же оттенков и проверили по контрасту. Она отдельно отмечена на ревью, а не выдаётся за оригинал.
- **Шрифты: Lora + Source Sans 3**, а не Lora + Outfit. У Outfit нет кириллицы (0 из 64 русских букв в файле Google Fonts). Оба шрифта вариативные, лежат в `res/font`, провайдер шрифтов не нужен. Жирных начертаний нет, как в референсе.
- **Иконки: Material Symbols Rounded, вес 300**, как vector drawable, а не Phosphor. Источник — npm-пакет `@material-symbols/svg-300` 0.47.6 (Apache 2.0); файлы конвертированы в тот же формат, что и прежние, шрифт иконок не подключается.
- **Бренд**: жёлтый ColaBike остаётся только в знаке, песок референса — точечный цвет интерфейса.
- **Поверхности непрозрачные.** `backdrop-blur` референса в Compose не воспроизводится; глубину держит hairline, тень — только у плавающей панели.

## Material 3 Expressive: решение ADR 0001 остаётся

Issue требовал перед обновлением сверить stable API. Проверено 03.10.2026 по Google Maven:

| Артефакт | Stable | Последняя версия |
| --- | --- | --- |
| `material3` | 1.4.0 | 1.5.0-alpha29 |
| `material3-adaptive-navigation-suite` | 1.4.0 | 1.5.0-alpha29 |
| `adaptive-navigation3` | 1.3.0 | 1.4.0-alpha02 |
| `navigation3-ui` | 1.2.0 | 1.3.0-alpha01 |

Все закреплённые версии — последние stable. `MaterialExpressiveTheme` и `MotionScheme` по-прежнему только в alpha, поэтому остаёмся на 1.4.0: крупные радиусы, пружины `ColaMotion` и навигационные компоненты Material. Пересмотр — когда выйдет stable material3 1.5.

## Навигационная оболочка

- **Один стек на раздел** по рецепту Navigation 3 «multiple back stacks» из `.claude/skills/navigation-3`: уход из раздела не сбрасывает его стек, прокрутку и ViewModel. Прежняя схема (`selectTab` очищал стек) терялась на «Велосипед → другая вкладка → Велосипед».
- **Выход через стартовый раздел** (Велосипеды): стандартное поведение Android, предсказуемое для «назад».
- **Показываются только разделы с экраном.** В `TopLevel` описаны все пять целевых (Лента, Велосипеды, Покатушки, Сообщения, Профиль), но флаг `available` включается вместе со срезом, который их реализует. Вкладка в пустую заглушку не допускается.
- **Своя плавающая панель навигации** (`ColaNavigationBar`) вместо `NavigationBar` Material: это подпись референса, а готового плавающего компонента в stable material3 1.4 нет (`FloatingToolbar` — Expressive, закрыт). Рейка на широких окнах — Material `NavigationRail`.

## Отклонённые варианты

- **material3 1.5.0-alpha** ради Expressive: фундамент не должен переписываться из-за переименований в alpha.
- **Outfit через провайдер шрифтов или без кириллицы**: нет Google-сервисов, нет русских букв.
- **Phosphor как шрифт иконок**: другой стиль, чем Material Symbols, которые требует issue, и лишний шрифт.
- **Размытие подложки** (`RenderEffect`, backdrop blur): дорого по батарее, не воспроизводимо на скриншотах JVM.
- **Единый общий стек со сбросом при смене вкладки**: теряет контекст, а это условие приёмки.
