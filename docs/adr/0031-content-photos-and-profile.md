# 0031. Лента, фотографии и собственный профиль

Статус: принято, 8 октября 2026. Продолжение [#61](https://github.com/grayhex/colabike-android/issues/61).

Лента различает содержание публикаций: автор/дата предшествуют фото велосипеда,
маршруту поездки либо заголовку и выдержке журнала. У записи нет выдуманной обложки:
API summary её не предоставляет. Каталог сохраняет компактную композицию и контракт ADR 0026.
Имена автора переносятся целиком; счётчики используют локальное числовое форматирование.

Фото велосипеда остаётся `Fit` в контейнере постоянной высоты. Во время загрузки он показывает
скелетон; полученное изображение появляется через `ColaMotion.effects`, изображения из memory
cache и reduced motion — сразу. Паспорт/комплектация разделяются линиями вместо вложенной
карточки. Раскрытие меняет высоту через `spatial`, шеврон — через `fastSpatial`; новое нажатие
меняет текущую цель, ввод не блокируется.

Полноэкранная галерея сохраняет индекс при закрытии. Её собственная тёмная тема обеспечивает
светлые органы управления независимо от темы приложения. Один палец при масштабе 1× листает,
при увеличении — двигает фото; pinch не отдаётся pager. Увеличение/сброс доступны кнопкой ≥48 dp,
масштаб ограничен 1–4×, панорамирование — границами увеличенного кадра. Double tap/кнопка
анимируются, непосредственный pinch следует за пальцами. Системный Back закрывает Dialog.
Это существующий modal viewer, не новый Navigation 3 destination; отмена predictive-жеста
галереи не заявлена без отдельной device-проверки. Ошибка загрузки сохраняет различие
удалённой фотографии и временного отказа с повтором.

Профиль начинается с личности и двух публичных велосипедов, затем идут сохранённое и
настройки. Превью запрашивает `people.bikesOf(account.id, limit=2)`, поэтому не показывает
приватные велосипеды как публичные. Модель принадлежит экрану в сессии, обновляется после
изменения велосипеда; отменённый старый ответ не заменяет новый. Ошибка превью оставляет
профиль доступным и предлагает повтор. Подтверждение почты — явный переход на сайт в группе
«Аккаунт», без имитации отсутствующей операции API.

Тема наблюдает за `ANIMATOR_DURATION_SCALE`: смена настройки обновляет текущую композицию.
При reduced motion раскрытие и увеличение мгновенны, фото не затухает, скелетоны неподвижны.
Физический frame timing и ручной TalkBack требуют отдельной финальной приёмки.
