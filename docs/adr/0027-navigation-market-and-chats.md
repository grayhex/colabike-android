# ADR 0027. Рынок внизу, чаты наверху, фильтры одной строкой

Статус: принято в рамках [issue #57](https://github.com/grayhex/colabike-android/issues/57), 07.10.2026, первый из трёх PR (каталог, навигация, покатушки и «О приложении»; серверные контракты мастера и сам мастер — следующие). Уточняет [ADR 0002](0002-visual-direction-and-shell.md), [ADR 0013](0013-market.md), [ADR 0011](0011-messenger.md), [ADR 0023](0023-graphite-lime-redesign.md).

## Что решено

- **Нижняя панель и рейка: Лента → Велосипеды → Покатушки → Рынок → Профиль.** `TopLevel.Market` (корень `Destination.Market()`, флаг `market`) заняла место чатов. Раздел «Рынок» — тот же нативный каталог объявлений: поиск, фильтры, карточки, сохранённое, контакт продавца. Значка «Объявления» в шапке «Велосипедов» больше нет; каталог компонентов там остаётся. Если сервер выключил рынок, вкладки нет (как раньше у любой функции).
- **Чаты — кнопка рядом с колокольчиком** (`HeaderActions`: чаты и уведомления, по очереди, у каждого свой счётчик; у чатов счётчика не было и нет). Она стоит в верхней панели корня каждого раздела (Лента, Велосипеды, Покатушки, Рынок, Профиль) и открывает прежний список бесед **поверх текущего экрана**: `Destination.Messages` кладётся в стек раздела, где человек сейчас, «Назад» возвращает ровно на исходный экран и его положение. Флаг `chat` убирает кнопку. Гость видит кнопку, как раньше видел вкладку, и за ней — приглашение войти.
- **Беседа открывается там, где человек.** Ссылка, пуш или уведомление о беседе (`Navigator.go(Destination.Conversation)`) открывают её поверх текущего раздела, а под ней — список бесед (если его нет в стеке), так что «Назад» идёт в список, как шло раньше с корня вкладки. На широком окне список и беседа стоят рядом, как прежде. Диалог «новая беседа» и экран беседы по-прежнему прячут нижнюю панель на compact.
- **Объявление по ссылке попадает в раздел «Рынок»** (`Destination.Listing`, `Destination.Market`), а не в «Велосипеды». Входящий `/market/<uuid>` и `market` в уведомлениях ведут туда же. Профиль → «Сохранённые объявления» открывает прежний экран поверх профиля.
- **«Велосипеды»: нет надписи COLABIKE; под поиском одна строка** — [Все ▾] [Все категории ▾] [+ Добавить]. «Все / Мои» и категория — выпадающие фильтры (`ColaDropdownChip`): подпись — выбранное значение, значение не по умолчанию заливает пилюлю лаймом. Категории можно выбрать несколько (список остаётся открытым), «Все категории» сбрасывает только их; подпись при нескольких — «MTB +1». Поиск, область и категории работают вместе и не сбрасывают друг друга, VM живёт в записи стека, поэтому после возврата из велосипеда или редактора фильтры и позиция те же. «Добавить» — акцентное действие, только вошедшему; оно открывает форму, которую делает следующий PR. Строка не переносится на обычном экране (проверено на 360 и 412 dp); при шрифте от 1,3 пилюли остаются одной строкой, а кнопки шапки уходят под заголовок, как раньше.
- **«Покатушки»: по умолчанию «Состоявшиеся».** `RideSegment.Default = Completed` (первым в списке), раздел открывается на состоявшихся. Все фильтры — одна строка над поиском: выпадающий список «Состоявшиеся / Ближайшие / Мои планы / Мои поездки» (личные — вошедшему) и «Хочу кататься». Вручную выбранный список, поиск и прокрутка сохраняются при возврате из карточки (VM в записи стека). У `Destination.Rides` нет параметра списка, поэтому ссылки на покатушки (`Ride`, `Intent`, `BikeRides`, участие) умолчание не затрагивает.
- **«О приложении»:** имя, версия и короткая строка «Сборка N». Описание «Нативное приложение…» и строка про контракт API убраны; ссылки (справка, поддержка, сайт, условия, политика, лицензии) на месте. Версия и сборка — из `BuildConfig`; скриншоты по-прежнему подставляют фиксированный `BuildInfo`.

## Почему так

- Чаты переносятся не в «ещё одну вкладку», а в действие шапки: так их видно с любого экрана, нижняя панель получает рынок (который раньше прятался за значком), а возврат из чатов — ровно туда, откуда пришли (стек раздела, не отдельный раздел).
- Выпадающий фильтр вместо строки чипов даёт одну строку на любом экране и оставляет всё доступным: ничего не убрано, ни одна категория, ни один список покатушек.

## Проверка

- `NavigatorTest`, `NavigatorFeaturesTest`: состав и порядок разделов, чаты поверх текущего экрана, беседа по ссылке со списком под ней, объявление в рынке, флаги.
- `ShellNavigationTest`, `MessagesFlowTest`, `MarketFlowTest`, `FeaturesFlowTest`, `BikeFlowTest`, `RidesFlowTest`: переходы, «Назад», сохранение состояния, фильтры.
- Скриншоты `bikes_*`, `rides_*`, `market*`, `messages*`, `about*` и каталог на 412 × 915 dp с двумя полными карточками (`CatalogAcceptanceTest`).

## Не здесь

Форма добавления велосипеда, справочники сайта и мастер с разбором комплектации — следующие два PR этой задачи (нужны операции API v1 в cola). Счётчик непрочитанных сообщений: у чатов его не было, и этот PR его не вводит.
