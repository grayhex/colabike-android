# ADR 0025. Выбор карты: OpenStreetMap и Яндекс Карты

Статус: принято в рамках [issue #43](https://github.com/grayhex/colabike-android/issues/43), 07.10.2026, вторая из двух частей (первая — [ADR 0024](0024-map-basemap.md), OpenStreetMap по умолчанию).

## Решение

- **Настройка «Профиль → Карта»** с двумя строками: «OpenStreetMap — по умолчанию» и «Яндекс Карты». Хранится на устройстве в `AppSettings.mapProvider` (SharedPreferences, не привязана к аккаунту), переживает перезапуск, применяется ко всем экранам маршрутов сразу, без перезапуска приложения. Неизвестное значение (после отката версии) читается как OpenStreetMap. Варианта «Без подложки» нет: однотонный фон остаётся только аварийным.
- **Одна дверь для обеих карт.** Экраны по-прежнему видят только `RouteMaps`. За ним `ChoosingRouteMaps`: читает настройку и показывает `MapLibreRouteMaps` (OSM) или `MapKitRouteMaps` (Яндекс). Маршрут, разрывы приватности и камера одинаковы: Яндекс получает те же линии по одной полилинии на линию, между частями отрезка нет; старт и финиш — те же метки; границы маршрута с отступом 40 dp; один участок точек — масштаб 16; север сверху, наклона нет; камера переживает поворот экрана; страница ушла — SDK останавливается, в фоне не работает.
- **Официальный SDK Яндекса** — `com.yandex.android:maps.mobile:4.45.0-lite` (Maven Central; «lite» без навигации и поиска, нужна только карта). Неофициальных тайлов Яндекса в MapLibre нет. Тёмная тема — штатный ночной режим карты (`isNightModeEnabled`), без перекраски. Логотип Яндекса на карте показывает сама библиотека.
- **Ключ — свойство сборки `colabike.yandexMapsApiKey`**, `BuildConfig.YANDEX_MAPS_API_KEY`; не коммитится, на сервере не лежит. Нужен **ключ мобильного приложения**: ключ JavaScript API сайта — другой продукт и в Android SDK автоматически не годится (проверяет владелец при выпуске ключа). Формат проверяется при сборке (`[A-Za-z0-9-]{8,80}`). Серверных секретов Яндекса или ColaBike в приложении нет.
- **Без ключа Яндекса нет совсем:** раздел «Карта» скрыт (выбор из одного пункта — шум), SDK не загружается и не запускается, во всех экранах OpenStreetMap. Если в настройках осталось «Яндекс», а сборка уже без ключа, показывается OpenStreetMap без подписи.
- **Возврат на OpenStreetMap — автоматический и честный.** Если SDK не запустился (нет библиотеки, класса, ключ отвергнут при старте) или карта не загрузилась за 25 секунд (нет сети, неизвестный сервису ключ), на том же экране показывается OpenStreetMap, а сверху — короткая подпись «Яндекс Карты недоступны, показана OpenStreetMap.» с кнопками «Повторить» (спросить Яндекс ещё раз) и «Оставить OpenStreetMap» (меняет настройку обратно). Сбой помнится до конца запуска приложения или до нового выбора, чтобы не мучить человека 25-секундным ожиданием на каждой карте; пустого экрана нет ни на одном шаге.
- **Без Google Play Services.** У POM MapKit две зависимости: `play-services-location` и `play:integrity`. Gradle исключает обе (`checkNoPlayServices` остаётся зелёным), R8 получает `-dontwarn` на эти пакеты. SDK ссылается на них только в классах, которые нужны при определении местоположения телефона и при аттестации, и ни то ни другое приложение не запрашивает. Это проверяется эмулятором без GMS (`YandexMapRenderTest`).
- **Разрешения.** Манифест SDK просит `ACCESS_FINE_LOCATION`, `ACCESS_WIFI_STATE`, `CHANGE_WIFI_STATE`, `RECEIVE_BOOT_COMPLETED`, `WAKE_LOCK` и `ACCESS_NETWORK_STATE`. Приложение убирает первые четыре (`tools:node="remove"`); `ManifestPermissionsTest` следит за итоговым манифестом: точной геолокации, фона и изменения Wi-Fi нет. Карту только смотрят.
- **Лицензия.** Условия использования API Яндекс Карт указаны на экране «Лицензии» со ссылкой; библиотека распространяется без изменений.

## Цена

- **Размер.** Нативная библиотека MapKit 19–29 МБ на архитектуру (против 8–11 у MapLibre). Универсальный release APK вырос примерно с 46 до 159 МБ (в нём четыре архитектуры без сжатия, 16 КБ-выравнивание сохранено, `check-native-alignment.sh` зелёный). Для RuStore рекомендуется AAB или разделение по ABI (`arm64-v8a` почти для всех устройств с Android 12+): примерно 40 МБ на устройство. Решение о фильтре ABI — за владельцем, как и в ADR 0009; в CI нужны все четыре (эмуляторы x86_64).
- **Минимальная версия Android** SDK — 26, у приложения 31, нужен OpenGL ES 3.0 (у MapLibre тоже).

## Что не проверено

- Живая работа на устройстве с настоящим ключом: тайлы, ночная схема, масштаб, логотип, поведение при неверном ключе. Тест эмулятора показывает только, что SDK запускается без Google-сервисов и что экран при любом исходе получает ответ (карта загрузилась или «недоступна»).
- Как именно SDK отвечает на неверный ключ: не гарантируется, что `onMapLoaded` не придёт при пустых тайлах; тогда вместо возврата на OpenStreetMap будет пустая карта Яндекса с логотипом. Это проверяет владелец при выпуске ключа; при необходимости порог загрузки уточнится по `MapLoadStatistics`.
- Условия бесплатного использования MapKit в приложении из RuStore (лимиты запросов, обязательные элементы) читает и подтверждает владелец.

## Отклонённые варианты

- **Яндекс Карты по умолчанию.** Нужны ключ и договор владельца; OpenStreetMap работает сразу.
- **Яндекс только в режиме отладки, без экрана выбора.** Не отвечает задаче: выбор должен быть у человека.
- **Показывать строку «Яндекс» без ключа, недоступной.** Мёртвая строка в настройках у каждого пользователя сборки без ключа; проще не показывать.
- **Зависимость от MapKit только при заданном ключе (flavors или отдельный модуль).** Сборка без ключа стала бы легче, но CI (R8, 16 КБ, no-GMS, манифест) не проверял бы путь с Яндексом; решение можно вернуть отдельно, если размер APK станет главным.
