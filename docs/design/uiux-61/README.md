# Композиция ColaBike — 8 октября 2026

Продолжение «Графита и лайма», [задача #61](https://github.com/grayhex/colabike-android/issues/61).
Это рабочая спецификация реализации. Пользователь поручил автономную реализацию с приёмкой
целого результата; промежуточные решения не выдаются за проведённое пользовательское исследование.

## Референсная доска

Источники: опубликованные разработчиками изображения в Google Play,
[Strava](https://play.google.com/store/apps/details?id=com.strava&hl=en) и
[Komoot](https://play.google.com/store/apps/details?id=de.komoot.android&hl=en), просмотрены
8 октября 2026. Версия установленного приложения не установлена: это анализ опубликованных
изображений, а не полевой тест приложений. Чужие изображения и фирменные элементы не включены
в репозиторий или приложение.

| Наблюдение | Наше решение | Зачем |
| --- | --- | --- |
| Strava: в активности карта предшествует результатам; три крупных числа читаются без рамок | Разрешённый маршрут → название → дистанция / время в движении / набор высоты на свободном холсте | Сначала понять поездку, потом изучать её |
| Strava: фотография и результат организуют социальную публикацию | Разная композиция велосипеда, поездки, записи журнала, объявления | Лента узнаётся по содержанию, а не по однотипным контейнерам |
| Komoot: нейтральная подложка, контрастная линия с обводкой, отдельные маркеры и масштаб | Подложка в обеих темах, трек с halo, начало/конец, fit, масштаб, атрибуция | Карта отвечает «где и какой маршрут», не служит украшением |
| Komoot: основное число сильнее единицы; действия не конкурируют с картой | Крупный результат, спокойные подписи, одно первичное действие на контекст | Быстрое чтение во время подготовки к поездке |

Собственный язык: графит / прохладная бумага, Inter, лайм / олива, Material Symbols Rounded 300.
Без градиентных подложек, светящихся рамок, псевдокарт и декоративных графиков.

## Шесть целевых композиций

| Экран | Порядок внимания на телефоне | Широкое окно | Основное действие |
| --- | --- | --- | --- |
| Лента | Автор и контекст → фото велосипеда / маршрут поездки / заголовок и выдержка журнала → факты → реакция | Читаемая колонка; detail после выбора, без растягивания текста | Открыть публикацию |
| Каталог | Компактные фильтры → целый велосипед на спокойной подложке → бренд/модель → автор и счётчики | Сетка до выбора, список/detail после выбора | Открыть велосипед; добавление в шапке |
| Велосипед | Фото целиком → единственное название → автор/реакция → краткое описание и паспорт → комплектация и журнал | Фото и факты в ограниченной колонке, удобный переход из списка | Смотреть фото / написать автору по контексту |
| Поездка | Маршрут → заголовок → три результата → автор/реакция → анализ и обсуждение | Карта и читаемые данные рядом | Открыть карту; у плана — участие |
| Совместная поездка | Место и время → темп/дистанция → люди и доступное действие | Карточки разумной ширины; сохранение фильтров | Найти компанию / написать |
| Профиль | Имя, город, описание → собственный контент → настройки отдельной группой ниже | Ограниченная колонка вместо растянутых строк | Открыть свои велосипеды / поездки |

На compact сохраняется договорённость ADR 0026: две полные карточки каталога на
412 × 915 dp при fontScale 1.0 и зазоры не менее 8 dp. Изображение велосипеда — `Fit`,
включая галерею, без искусственного обрезания колёс. Существующий исходный кадр может уже
содержать обрезанный велосипед; приложение не обещает восстановить отсутствующие пиксели.

## Группировка и акценты

- Карточка отделяет самостоятельный объект списка. Паспорт, заголовок и статистика одного
  объекта не требуют вложенных рамок. Настройки группируются строками через разделители.
- Лайм выделяет первичное действие, выбор или маршрут. Справка — обычный вторичный текст.
  Реакция имеет свой семантический цвет; ошибка — цвет ошибки и понятное действие.
- Не пропускать подписи ради плотности. В нижней панели: «Лента / Вело / Поездки / Рынок /
  Профиль», 12 sp с настоящим системным масштабом. TalkBack и rail используют полные имена.
  Если слова не помещаются, панель перестраивается в два ряда. Рейка растёт по ширине текста
  и прокручивается по вертикали. Это явная замена ограничения 11 sp / fontScale 1.15.
- Бейдж входит в измеряемую область кнопки. Ноль не рисуется; 1–99 — точное число;
  выше — 99+. Полная фраза уведомлений читается один раз, без отдельного озвучивания цифр.
- Единицы и суммы форматируются общей системой, не склеиваются по-разному на каждом экране.
  Длинные имена переносятся; число не отделяется от своей единицы случайным переносом.

## Motion

| Триггер | Переход | Прерывание | «Убрать анимации» |
| --- | --- | --- | --- |
| Выбор вкладки | Цвет текста/значка/плашки: `ColaMotion.effects` | Новое значение из текущего цвета, без блокировки клика | Мгновенное новое состояние |
| Реакция | Цвет `effects`, небольшое увеличение сердца `fastSpatial` | Повторный запрос блокируется лишь до ответа; ошибка возвращает предыдущее состояние | Мгновенное состояние; без вращающегося индикатора |
| Сохранение реакции | Индикатор в зарезервированном месте значка, число не скачет | Успех или ошибка прекращает индикатор | Статичное сердце, доступная подпись «Сохраняем» |
| Список → detail → назад | Navigation 3, системный predictive back | Отмена жеста оставляет исходный экран и состояние | Системная шкала длительности |
| Галерея | Стабильный индекс фото и контейнер, переход по выбранному объекту | Назад возвращает тот же элемент списка | Без декоративного движения |
| Раскрытие секции | Изменение размера на `spatial`, поворот шеврона | Новый целевой размер из текущего, ввод доступен | Мгновенное раскрытие |
| Применение фильтра | Сохранить геометрию списка во время запроса; заменить результат после ответа | Старый запрос отменяется; актуален последний выбор | Тот же порядок, без движения |
| Загрузка фото | Стабильное соотношение сторон; короткое появление содержимого | Ошибка меняет только содержимое контейнера | Сразу фото или статичная ошибка |

Первые три строки реализуются общими компонентами; остальные проверяются с вертикальными
сценариями следующих этапов. Shared transition не является обязательной декорацией:
его вводят лишь при устойчивой идентичности объекта и корректном back/cancel.
Тактильный отклик — только явное переключение реакции (`ToggleOn/Off`), через системный
`LocalHapticFeedback`; программный откат не вибрирует. Переходы по вкладкам не вибрируют.

## Реалистичные данные и доказательства

`RealisticScenesTest` воспроизводит шесть сценариев в светлой/тёмной теме и с текстом 200%,
на 412 × 915 и 1200 × 900 dp. Это автоматические рендеры приложения, не макеты в редакторе.
Фотографии хранятся только в test resources; источники и лицензии —
[реестр](../../../app/src/test/resources/visual/photos/sources.json).
Имена людей, аккаунты, описания и численные результаты вымышлены. Имена моделей в фото
не доказывают комплектацию: примеры не являются объявлениями о продаже.

Фотографии скачаны в виде миниатюр Wikimedia без ретуши. Для распространения снимков
с включёнными фотографиями необходимо сохранять авторство и применимую CC BY-SA 2.0/4.0
к фотографическим производным; лицензия исходного кода не заменяет лицензию фото.
Панорама, тёмный/сложный фон, вертикальный кадр, неполный исходный кадр и CC0-фото
содержатся в наборе для отдельной проверки галерей и ошибок. Конкурентные изображения
не используются как тестовые данные.

Автоматические проверки не заменяют TalkBack на устройстве, исследование с пятью
велосипедистами и измерение jank на физическом устройстве среднего класса. Результаты
этих проверок допускается записывать только после фактического проведения.

## Реализованный сценарий поездки

[ADR 0030](../../adr/0030-route-previews-and-hierarchy.md) фиксирует карточку с маршрутом,
композицию detail, очередь и кэши превью, масштаб и fit интерактивных карт.
Снимки `realistic_feed_*`, `realistic_ride_*` и `ride_page_*` показывают этот этап;
исходное состояние для сравнения закреплено commit `ddeb05f` (PR #63).
В native-снимках сохраняется атрибуция; изображения Roborazzi по-прежнему являются схемами.
