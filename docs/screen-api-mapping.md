# Экраны и операции API v1

Какой экран какие операции вызывает, что из контракта он показывает и чего в нём нет. Обновляется в каждом PR, который добавляет экран или операцию. Операции и поля сверяются с закреплённым снимком `api/openapi.json`; чего нет в контракте, не показывается и не имитируется.

| Экран | Операции | Что показывает | Чего нет, потому что нет в контракте или срезе |
| --- | --- | --- | --- |
| Вход | `POST /auth/sessions` (пароль; код Яндекса — выключен) | форма, ошибки, «Смотреть без входа», ссылки на сайт | регистрация, восстановление пароля (на сайте) |
| Велосипеды (список) | `GET /bikes` (`scope`, `q`, `category`, `limit`, `cursor`) | карточки с обложкой, счётчики лайков и комментариев, поиск по названию, бренду, модели и автору, фильтр по типам (несколько типов — «или»), «Мои» для вошедшего | расширенные фильтры — на экране «Поиск» |
| Велосипед | `GET /bikes/{id}`, `PUT`/`DELETE /bikes/{id}/like` | галерея с просмотром на весь экран, признаки классификации, лайк, «Поделиться» (публичные), автор (открывает его страницу), описание, паспорт (вес, пробег, размер рамы, цвет), цена, если её видно зрителю, компоненты по группам владельца, ссылка на страницу производителя | оценки полноты и апгрейда (`scores`: смысл для людей не определён), комментарии и журнал (срез #6) |
| Человек | `GET /users/{ref}`, `GET /users/{ref}/bikes`, `PUT`/`DELETE /users/{id}/follow` | имя, @username, аватар, место, «на ColaBike с …», «о себе», числа (велосипеды, подписчики, подписки), кнопка «Подписаться» / «Вы подписаны» / «Друзья», «Это вы» для себя, публичные велосипеды страницами | редактирование, блокировка, жалобы (нет контракта) |
| Подписчики, Подписки | `GET /users/{ref}/followers`, `GET /users/{ref}/following` | строки «аватар, имя, @username», страницы по курсору | — |
| Поиск | `GET /experience/bikes` (`q`, `category`, `suspension`, `electric`, `fatbike`), `GET /experience/users` (`q`) | две вкладки, фасеты велосипедов, результаты страницами, «Что ищем?» / «Ничего не нашли» / ошибка с повтором | поиск по компонентам с подсказками, сохранённые поиски (нет в контракте) |
| Профиль | `GET /me` | имя, username, место, «о себе», подтверждение почты, тема, «О приложении» | редактирование профиля, смена аватара (нет write-контракта) |
| Устройства и входы | `GET /auth/sessions`, `DELETE /auth/sessions/{id}`, `DELETE /auth/sessions/current` | список сеансов, пометка «это устройство», завершение чужих, выход | выход «везде» одним запросом (нет в контракте) |
| О приложении, лицензии | — | версия, ссылки на условия и политику (сайт), тексты лицензий | — |

## Адреса «Поделиться» и входящие ссылки

- «Поделиться» отправляет `https://colabike.ru/b/<uuid>`: сайт перенаправляет (308) на канонический `/b/<slug>-<id>`. Канонический адрес приложение построить не может: в контракте нет `publicId` и `slug`. Пробел записан в [ADR 0003](adr/0003-account-guest-and-web-flows.md).
- Входящий `/b/<uuid>` открывает карточку велосипеда, `/u/<username>` — страницу человека; `/b/<slug>-<id>` приложение открыть не может и отдаёт сайту.
