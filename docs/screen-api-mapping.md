# Экраны и операции API v1

Какой экран какие операции вызывает, что из контракта он показывает и чего в нём нет. Обновляется в каждом PR, который добавляет экран или операцию. Операции и поля сверяются с закреплённым снимком `api/openapi.json`; чего нет в контракте, не показывается и не имитируется.

| Экран | Операции | Что показывает | Чего нет, потому что нет в контракте или срезе |
| --- | --- | --- | --- |
| Вход | `POST /auth/sessions` (пароль; код Яндекса — выключен) | форма, ошибки, «Смотреть без входа», ссылки на сайт | регистрация, восстановление пароля (на сайте) |
| Велосипеды (список) | `GET /bikes` (`scope`, `q`, `category`, `limit`, `cursor`) | карточки с обложкой, счётчики лайков и комментариев, поиск по названию, бренду, модели и автору, фильтр по типам (несколько типов — «или»), «Мои» для вошедшего | расширенные фильтры — на экране «Поиск» |
| Велосипед | `GET /bikes/{id}`, `PUT`/`DELETE /bikes/{id}/like` | галерея с просмотром на весь экран, признаки классификации, лайк, «Поделиться» (публичные), автор (открывает его страницу), описание, паспорт (вес, пробег, размер рамы, цвет), цена, если её видно зрителю, компоненты по группам владельца, ссылка на страницу производителя, вход в обсуждение и в журнал велосипеда | оценки полноты и апгрейда (`scores`: смысл для людей не определён), комментарии открываются отдельным экраном |
| Человек | `GET /users/{ref}`, `GET /users/{ref}/bikes`, `PUT`/`DELETE /users/{id}/follow` | имя, @username, аватар, место, «на ColaBike с …», «о себе», числа (велосипеды, подписчики, подписки), кнопка «Подписаться» / «Вы подписаны» / «Друзья», «Это вы» для себя, публичные велосипеды страницами | редактирование, блокировка, жалобы (нет контракта) |
| Подписчики, Подписки | `GET /users/{ref}/followers`, `GET /users/{ref}/following` | строки «аватар, имя, @username», страницы по курсору | — |
| Поиск | `GET /experience/bikes` (`q`, `category`, `suspension`, `electric`, `fatbike`), `GET /experience/users` (`q`) | две вкладки, фасеты велосипедов, результаты страницами, «Что ищем?» / «Ничего не нашли» / ошибка с повтором | поиск по компонентам с подсказками, сохранённые поиски (нет в контракте) |
| Лента | `GET /me/feed` (`type`, `limit`, `cursor`) | велосипеды, записи журнала, покатушки и объявления тех, на кого подписан вошедший; фильтры «Всё / Покатушки / Записи» (серверные); для гостя — объяснение и вход, запроса нет | карточка объявления не открывается (срез #9); неизвестный тип элемента отбрасывается |
| Журнал велосипеда | `GET /bikes/{id}/journal` | записи страницами, новые сверху; черновики видит только владелец | — |
| Запись журнала | `GET /journal/{id}`, `PUT`/`DELETE /journal/{id}/save` | вид, дата события, пробег, велосипед и автор, фото, текст (Markdown), снимок комплектации, счётчики, «Сохранить», вход в обсуждение | лайк записи и признак «сохранено» (нет в контракте) |
| Сохранённое | `GET /me/saved/journal` | записи, которые сохранил вошедший, новые сохранения сверху | — |
| Покатушки (раздел) | `GET /rides/upcoming`, `GET /rides` (`q`, `cursor`), для вошедшего `GET /me/rides/upcoming` (до 20, без курсора), `GET /me/rides` | четыре списка: «Ближайшие», «Состоявшиеся», «Мои планы» (роль, отмена, «условия изменились», точка встречи), «Мои поездки» (в том числе приватные и отменённые без страницы); серверный поиск в двух публичных; гость — без личных | поиск в личных списках, ответ на план и создание плана (нет в контракте чтения), лайк покатушки (нет операции) |
| Покатушка, план | `GET /rides/{id}`, `GET /rides/{id}/analysis` (отдельный запрос, только если есть маршрут) | время в поясе устройства с подписью, показатели, описание, паспорт плана, «Едут / возможно», точка встречи или пояснение, автор, велосипед, «Комментарии»; маршрут (схема, карта на весь экран или рядом на широком окне, линии как дал сервер) и графики высоты, скорости, уклона и открытых автором пульса, каденса, мощности | подложка карты (ждёт адрес стиля от владельца, [ADR 0009](adr/0009-route-map-and-analysis.md)); приватная и отменённая покатушка отвечают 404 даже владельцу; 404 у разбора — раздела нет |
| Покатушки велосипеда | `GET /bikes/{id}/rides` (`q`, `cursor`) | состоявшиеся публичные покатушки одного велосипеда, поиск | у непубличного велосипеда строки нет (сервер ответил бы 404) |
| Уведомления | `GET /me/notifications` (`limit`, `cursor`), `GET /me/notifications/count` | колокольчик в шапке верхних экранов с числом (`99+`, если сервер насчитал предел); inbox страницами, кто что сделал и с каким объектом, точка у непрочитанного, переход к объекту, к обсуждению на комментарии или на сайт; гостю ни колокольчика, ни запросов | **пометка «прочитано» (в API v1 такой операции нет: число не уменьшается из приложения)**, push, группировка; формат якоря комментария в пути не описан в контракте |
| Сообщения (раздел), диалог | `POST /chat/token` (5 минут, публичный ключ приложения), дальше SDK Stream Chat напрямую с провайдером | подключение при первом показе раздела; список диалогов (только каналы ColaBike, где человек участник), диалог со сообщениями, ответами, реакциями набора SDK, «печатает», прочитанным, картинками через системный Photo Picker; «подтвердите почту» (403), «сообщения отключены» (503), повтор при сбое; гостю объяснение и вход, запросов нет; от 840 dp список и диалог рядом | push (нет FCM/GMS), звонки, видео, голосовые, файлы, опросы, переводы, значок непрочитанных на вкладке; сообщения не проходят через сервер ColaBike и не хранятся в приложении ([ADR 0011](adr/0011-messenger.md)) |
| Новое сообщение | `GET /chat/people` (без `q` — на кого подписан; с `q` от 2 знаков — поиск, до 20), `POST /chat/channels` (`Idempotency-Key` у группы) | поле поиска, люди, личный диалог по нажатию (открывается тем же каналом), группа: от 2 до 7 людей и название до 80 знаков; отказ «этому человеку нельзя написать» (404) | управление участниками группы после создания; `GET /chat/unread` (число готово в репозитории, на экране не показывается) |
| Человек: «Написать» | `POST /chat/channels` | кнопка рядом с «Подписаться» на странице другого человека; гостю — вход | — |
| Каталог компонентов | `GET /component-models` (`q`, `category`, `brand`, `sort`, `limit`, `cursor`), `GET /component-models/filters` | поиск сервера (название, бренд, прежние написания), порядок «Новые» / «Популярные», меню категорий и брендов со значениями сервера, карточки (обложка, бренд, название, категория, число публичных велосипедов), страницы по курсору; открывается значком в верхней панели «Велосипедов» | подсказки `/search/components`, вход из «Поиска» и по ссылке сайта (формат адреса модели в контракте не описан), избранное и сравнение ([ADR 0012](adr/0012-component-catalog.md)) |
| Модель компонента | `GET /component-models/{id}`, `GET /component-models/{id}/photos`, комментарии `…/comments` | название, бренд, категория, число публичных велосипедов, описание, галерея с просмотром на весь экран, авторство фото (загрузил(а), или источник с провайдером, лицензией и https-ссылками), пометка об архивной модели, обсуждение (общий экран), страница на сайте; слитая модель отвечает канонической; открывается из каталога, из комплектации велосипеда и записи журнала по `modelId` | установки, владельцы и приватные даты (API их не отдаёт); число комментариев |
| Комментарии (велосипед, запись журнала; покатушка и модель компонента — тем же экраном) | `GET /{bikes,journal,rides,component-models}/{id}/comments` (`cursor`, `focus`), `…/comments/{commentId}/replies`, `POST …/comments` (`Idempotency-Key`), `PATCH`/`DELETE …/comments/{commentId}` | корни старые сверху с превью ответов и «Показать ещё ответы», надгробия, ветка по ссылке, поле ввода (ответ, правка), счётчик знаков с 800, свои «Изменить» и «Удалить» с вопросом; гостю вместо поля — вход | реакции, вложения, упоминания с подсказками, права администратора (нет в контракте или не для приложения); `If-Match` не используется (последняя правка побеждает) |
| Профиль | `GET /me` | имя, username, место, «о себе», подтверждение почты, тема, «О приложении» | редактирование профиля, смена аватара (нет write-контракта) |
| Устройства и входы | `GET /auth/sessions`, `DELETE /auth/sessions/{id}`, `DELETE /auth/sessions/current` | список сеансов, пометка «это устройство», завершение чужих, выход | выход «везде» одним запросом (нет в контракте) |

## Адреса «Поделиться» и входящие ссылки

- «Поделиться» отправляет `https://colabike.ru/b/<uuid>`: сайт перенаправляет (308) на канонический `/b/<slug>-<id>`. Канонический адрес приложение построить не может: в контракте нет `publicId` и `slug`. Пробел записан в [ADR 0003](adr/0003-account-guest-and-web-flows.md).
- Входящий `/b/<uuid>` открывает карточку велосипеда, `/u/<username>` — страницу человека; `/b/<slug>-<id>` приложение открыть не может и отдаёт сайту.
